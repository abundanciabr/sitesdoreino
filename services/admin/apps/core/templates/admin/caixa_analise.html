Por isso não há um único número cravado neste arquivo. Os modais abrem por `:target` e fecham voltando para a âncora do próprio cartão (`#ficha-N`), que é o que faz a página voltar para onde a pessoa estava em vez de pular para o topo. Sem JavaScript: a porta manda `script-src 'self'` e esta célula não serve estático nenhum, então um modal com script custaria uma exceção de CSP para ganhar o que o CSS já faz. O que se perde é a tecla Esc; em troca, o botão "voltar" do navegador fecha, e o endereço de uma ideia aberta pode ser copiado e mandado para alguém. {% endcomment %} {% block titulo %}A análise | Caixa de Sugestões{% endblock %} {% block corpo %}
