O painel não veio nesta versão do sistema

A área administrativa está no ar, mas os arquivos do painel não chegaram junto com ela. Isso é falha da nossa esteira de publicação — não é você que fez algo errado, e nenhum dado do projeto se perdeu: o livro de ocorrências continua inteiro no repositório.

O que fazer: abra uma sessão do Claude Code e cole “o painel online está dizendo que não veio nesta versão”. O conserto é na etapa que copia a pasta do painel para dentro da imagem. Enquanto isso, o painel do seu computador continua funcionando normalmente.
