Por que dá para confiar neste mapa. Ele não é uma lista digitada à mão que alguém precisa lembrar de atualizar. O endereço de cada linha é conferido, a cada mudança no site, contra o roteamento de verdade e contra o código das 13 partes da plataforma: um robô que criar uma página nova e não a escrever aqui é reprovado antes de a mudança entrar, e o mesmo vale para uma linha que sobrar depois que uma página deixar de existir. Um endereço marcado molde não é um lugar só: é a forma de muitos — cada aluno, cada ideia, cada pedido tem o seu.

{% comment %} A LUZ DE "ESTÁ NO AR?" — e quem pergunta é o SEU navegador, não o servidor. Isso é de propósito: um servidor conferindo a si mesmo por dentro da rede do Docker não passaria pelo roteador nem pelo cadeado, e responderia "no ar" para uma porta que a internet não alcança. Daqui, o caminho é o mesmo que qualquer visitante faria. `redirect: "manual"` porque várias destas portas respondem com um desvio (para o login, por exemplo): sem isso o navegador seguiria o desvio até o Google e a pergunta morreria numa regra de origem cruzada. Com ele, o desvio JÁ É a resposta — a porta respondeu. A ilha entra na política de segurança por HASH (`apps/core/mapa_do_site.py`), nunca por `'unsafe-inline'`. {% endcomment %} {% endif %}
