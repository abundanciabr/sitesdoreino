{% comment %} A moldura das páginas PÚBLICAS desta célula (`/docs/`). Separada de `admin/base.html` de propósito, e a separação é a metade que importa: · aquela mostra "Meshcraft · Administração" e o nome de quem entrou — texto que um estranho não deve ver, e que aqui não existe para poder vazar; · aquela é `noindex`, porque área administrativa não se indexa. Esta é indexável: um documento público que ninguém acha é um documento que não foi publicado. Claro e não escuro, pelo mesmo motivo: o painel é ferramenta de operação, isto é página de leitura. O CSS é EMBUTIDO, como no vizinho — célula sob SCRIPT_NAME precisa de rota própria de estático para não dar 404 só em produção (`armadilhas/083`), e a tag `static` monta endereço do prefixo errado nessa situação (`armadilhas/102`). Sem fonte remota, sem script, sem imagem: uma página de texto não precisa de nada disso, e cada peça de fora é uma dependência que pode cair sozinha. {% endcomment %} {% block titulo %}Documentos{% endblock %} · Meshcraft
