### 3. A Mecânica do "Hub" na Prática (O que fazer)

Use a sua infraestrutura atual de arquivos locais (`file://`) para criar a seguinte estrutura:

* **Mantenha os arquivos de dados separados:** Continue com `fundacao-dados.js`, `retomada-dados.js`, `10x-dados.js`. Os agentes atualizam *apenas* o escopo em que estão trabalhando. O risco de um agente quebrar o painel inteiro cai para quase zero.
* **Crie o `hub-inbox.html`:** Este é o SEU arquivo de "Andar 1". Ele não possui dados próprios. O JavaScript dele importa *todos* os arquivos de dados dos outros painéis.
* **A Lógica do Hub:** O script do Hub varre todos os objetos de dados importados. Se ele encontrar a tag `precisa_de_dono: true` ou `status: vermelho` em *qualquer* lugar, ele "puxa" esse cartão e exibe na sua tela principal.
* **O Resultado:** Você abre um único arquivo no Chrome. Ele lê silenciosamente todos os painéis e joga na sua cara apenas o que está pegando fogo ou travando a fila. Se você quiser ver a história completa de um incidente, clica num link que abre o HTML do painel específico.

### 4. O Risco de Fadiga do "Anti-Teatro"

O seu mecanismo de "evidência crua colada, nunca descrição" para evitar que a IA minta é a melhor defesa comportamental possível. No entanto, os seus Prompts da Fase D e Fase E estão ficando imensos devido ao bloco cumulativo de "LIÇÕES DOS DESPACHOS ANTERIORES".
