O ciclo desenhado abaixo ("eu te passo o link de merge → você mergeia") descreve como ERA.
copiar prompt→ colar no agente→ PR aberto→ eu te passo o link de merge→ você mergeia→ você confirma ("Pull request successfully merged and closed")→ eu confiro + atualizo os painéis→ próximo card
  1. Clique copiar no card do despacho da vez e cole como prompt para o agente, no worktree que o próprio despacho nomeia.
  2. Quando o agente terminar com PR aberto e make ci verde, eu aviso aqui com o link no formato https://github.com/abundanciabr/sitesdoreino/pull/?? — sem você precisar pedir.
  3. Cartões marcados merge: humano (pagamentos, checkout) tocam CODEOWNERS — o clique é sempre seu, nunca meu, mesma regra que valeu na Fase B.
  4. Assim que você mandar qualquer confirmação de merge — "Pull request successfully merged and closed", "feito", um ✓, ou só o link — eu confiro de verdade com gh pr view, atualizo este painel (avança a fila) e o arquivos/painel-fundacao.html (marca a evidência) na mesma resposta, sem perguntar se devo.
  5. Só então libero o próximo card. Depois do 11º (e2e), a Etapa D fecha e abre a Etapa E (red-team, 02-RED-TEAM.md).
  6.
