⚠️ O anti-teatro: como impedir que um agente diga que fez sem fazer

Este é o coração do painel. Um agente sob pressão tende a relatar sucesso. A defesa não é confiar melhor — é tornar a mentira mecanicamente impossível de sustentar. Três regras valem em TODO card, e estão repetidas no rodapé de cada prompt:
  1. Evidência é saída crua colada, nunca descrição. "Rodei os testes e passou" não conta. O que conta é o texto que o comando cuspiu — make ci inteiro, o pytest com a contagem, o git diff --stat. Descrição de resultado é recusada por definição.
  2. Todo invariante/bug tocado exige vermelho→verde real (Lei 6): a saída do teste-guarda FALHANDO sem o fix e PASSANDO com o fix, as duas coladas. Sem o vermelho, não há prova de que o teste testa algo — um teste que nunca falhou pode estar verificando nada.
  3. Cada onda termina com um card de AUDITORIA (verde tracejado), executado por uma sessão DIFERENTE da que implementou. O auditor não confia no handoff: ele roda os comandos de novo, contra o repo real, e reporta PASS/FAIL por item de DoD. É o agente que não tem motivo para mentir conferindo o que teve.
Regra de ouro do mantenedor: antes de marcar qualquer card como concluído, o card de auditoria daquela onda tem que estar verde. Confirmação de merge é gatilho para conferir (gh pr view N --json state,mergedBy,mergeCommit), não substituto.
Como usar, passo a passo (o ritmo é deliberadamente lento):
  1. Abra a onda da vez. Faça primeiro os cards HOJE (são seus, manuais) — eles destravam o resto.
  2. Para cada card de despacho: clique no cabeçalho para abrir, copiar prompt, cole para um agente num worktree próprio. Cards da mesma onda com áreas distintas podem rodar EM PARALELO (a cerca de CI garante 1 PR = 1 célula).
  3. Agente entrega PR + evidência crua. Você mergeia (cards marcados merge: humano são sempre seu clique).
  4. Quando todos os despachos da onda estiverem mergeados, rode o card de AUDITORIA da onda numa sessão nova. Ele te devolve um PASS/FAIL por item.
  5. Só com a auditoria verde, avance para a próxima onda. Sem pressa — cada onda que fecha de verdade vale mais que três que "quase".
Legenda: merge: auto CI verde basta · merge: humano CODEOWNERS, seu clique · depende de X não comece antes de X · célula/área onde o trabalho mora.
