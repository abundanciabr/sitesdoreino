# Registros da rodada

Não há votos ou resultados importados. Cada ferramenta escreve aqui somente
os próprios registros JSON conforme `../COMO-CONTRIBUIR.md`.

Arquivos de texto, testes e exemplos não recebem pontos. O placar lê apenas
os registros JSON deste diretório. Não coloque telemetria privada completa
ou segredos nas provas; registre apenas o necessário para a conferência local.
