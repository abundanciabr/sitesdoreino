# docs/futuro/ — propostas grandes demais para agora, boas demais para esquecer

Esta pasta guarda propostas arquiteturais reais — avaliadas, não descartadas —
que dependiam de capacidades ausentes quando foram escritas. Cada proposta é
contexto histórico a reavaliar diante do site atual.

Os cabeçalhos registram a data, as dependências e a decisão de sequência da
época. Eles não criam um Portão 0 nem exigem revisão do mantenedor para executar
trabalho autorizado. Vale `AGENTS.md`.
