# docs/futuro/ — propostas grandes demais para agora, boas demais para esquecer

Esta pasta guarda propostas arquiteturais reais — avaliadas, não descartadas —
que dependem de capacidades que a plataforma ainda não tem. Elas não viram
despacho até a dependência ser satisfeita.

**Regra:** todo documento aqui carrega um cabeçalho dizendo (a) quando foi
proposto, (b) do que ele depende para deixar de ser prematuro, e (c) a decisão
de sequência tomada. Quando a dependência for satisfeita, o documento vira o
Portão 0 de um brief novo — revisado com o mantenedor antes de qualquer
despacho, exatamente como o Portão 0 da Fase 0 revisou contratos antes de
congelá-los.

Nenhum agente implementa um documento desta pasta sem esse rito.
