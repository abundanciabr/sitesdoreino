# Trabalho no site

Quando o mantenedor pedir uma mudança, faça o trabalho no site e entregue o
resultado funcionando. Use o código atual para localizar e ajustar a parte
pedida.

Antes de publicar, há backup. Se a prova falhar ou o site cair, o código volta
automaticamente para a última versão aprovada. O banco de dados não é
restaurado automaticamente.

Peça a palavra do mantenedor somente antes de gastar dinheiro real, apagar
dados ou expor um segredo.
