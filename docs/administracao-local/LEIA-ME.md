# Documentos da administração local

Esta pasta recebe os documentos do plano mestre que a tela local lista. Ela
fica dentro do checkout para que o lançador funcione em qualquer máquina e
worktree sem depender de um caminho absoluto.

Os documentos da pesquisa entram em um PR próprio. O lançador permite apontar
`ADMIN_PLANOS_DIR` para outra pasta sem editar arquivo versionado.
