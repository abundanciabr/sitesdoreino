# ChangeSpecs

Esta pasta guarda documentos que ligam uma sugestão da Caixa à implementação.
O formato de agosto de 2026 está preservado em
[`FORMATO-CHANGESPEC.md`](../caixa-de-sugestoes/FORMATO-CHANGESPEC.md) como
registro histórico. Seus campos, assinatura, divisão entre sessões e versões
imutáveis não condicionam trabalho autorizado hoje. Vale `AGENTS.md`.

Os arquivos existentes registram decisões e escopos da época em que foram
escritos. Para uma mudança atual, use o contexto útil deles e corrija o que
for necessário no próprio trabalho. O registro de aprovação da Caixa, quando
existir, descreve um evento do produto; ele não autoriza nem impede executar
um pedido.
